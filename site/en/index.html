Why IRNetFree Plus

A scan whose results you can trust

It walks any range with no cap, accepts only the right answer, and tells you when something spoils the results.

Any range, no cap

Cloudflare, Fastly, CloudFront and Gcore ranges are ready and update with one button. Even a /8 with 16 million addresses is walked without trouble.

Not only IPs, parameters too

TLS fingerprint, ALPN, fragment, finalMask, dialMode and Mux, in every permutation, on the same addresses.

A pass means the right answer

One lucky reply or an error page does not pass. A target must give the expected answer through the tunnel, and every failed row says why.

It checks its own path

If a VPN answers in place of the addresses, Plus says the results are not real. You can also send the scan through a SOCKS port.

An Xray server, the 3x-ui way

Inbounds, clients with quotas and expiry, outbounds, routing and a reverse proxy, with no web panel or database.

Built to work with IRNetFree

It imports IRNetFree's configs in one click and hands the best results back as links. Both apps run side by side.

Features

A complete scanner, with an Xray server beside it

All the details are in the guide (Persian).

What gets scanned

  • Every protocol: VLESS, VMess, Trojan, Shadowsocks, Hysteria2, WireGuard, MASQUE, WARP over MASQUE, and JSON configs
  • Addresses: IPv4, IPv6, CIDR and a-b ranges and domains
  • Ready ranges: Cloudflare, Fastly, CloudFront, CloudFront regional, Gcore, WARP MASQUE and WARP WireGuard
  • Each CDN's official list fetched from the CDN itself, with one button
  • Each port and SNI combined with each address

How many from each range

  • All of them: no cap, tested in batches, never listed in memory
  • N random from all: an even sample of all the ranges together
  • N from each range or N from each block, so a /22 gets four times the share of a /24
  • A history of tested addresses, so the next run tries fresh ones

Config parameters

  • TLS fingerprint, ALPN, cipherSuites, fragment, finalMask, dialMode, Mux and XHTTP mode
  • Every row has a switch: on, its values multiply the run
  • What only Xray-PattN runs is tested on that core alone
  • Parameter sets can be saved by name

Accurate results

  • Two stages: a quick filter on everything, then a speed test on the best only
  • Pre-check: a dead address goes out on a TCP or TLS check
  • Score: success rate, then median delay, then jitter
  • Why it failed: no TCP, TLS, core, tunnel closed, timeout, wrong answer or unstable

Scan path and SOCKS port

  • Check the path: an address that cannot exist must not answer; if it does, the app warns you
  • Scan through a SOCKS port: for example IRNetFree's direct port, so the VPN stays on
  • The limits of that mode are in the guide

After the scan

  • Copy any row as a link or JSON, with the same address and parameters
  • Copy the best links, ready for IRNetFree
  • A summary per combination: passes, rate, median delay and best address
  • CSV and JSON export

An Xray server, the 3x-ui way

  • Seven tabs: overview, inbounds, outbounds, routing, reverse, settings and log
  • Inbounds: VLESS, VMess, Trojan and Shadowsocks over TCP, WebSocket, gRPC and XHTTP, with none, TLS or Reality
  • Clients: quota, expiry, reset cycle, link and QR, turned off automatically when used up
  • Reverse proxy: portal and bridge wizards for a device behind NAT
  • Closing the window while the server runs keeps it running in the tray

A server with no screen? Run it from source

Server with no screen

The same pages on a web port, with Node.js
git clone https://github.com/sadrazkh/Irnetfree_xray-client-plus.git
cd Irnetfree_xray-client-plus
node src/server/server.js --port 6970
ssh -L 6970:127.0.0.1:6970 user@server

The pages listen on 127.0.0.1 by default; open them in your own browser through this SSH tunnel. Any other address needs a token. Details

Start in a minute

Five steps to the best addresses

Get the core

Open the app and get the Xray core from Settings → Cores.

Turn the VPN off

A VPN in TUN mode answers in place of the addresses. Check the path tells you where you stand.

Add a config

Paste a config link on the Configs page, or press From IRNetFree.

Scan

Choose the config and a range, for example Cloudflare and N random from all, then Start scan.

Take it to IRNetFree

Press Copy the best links and paste them into IRNetFree.

FAQ

Answers to what people ask most

Does Plus replace IRNetFree?

No. Plus is not a client and connects nothing. Plus finds good addresses and parameters and runs a server; IRNetFree connects.

Why must the VPN be off while scanning?

A VPN in TUN mode answers in place of the addresses, so everything looks alive. Either turn it off, or open a direct port in IRNetFree and scan through it. Details

Is an address it found good for any config?

A result holds for the config you scanned. Scan again for another config.

Does Plus need admin rights?

No. It runs as a normal user. Only the Server tab's firewall button on Windows asks UAC, for that one command.

My Mac won't open the app.

The app is not signed with an Apple certificate, so a plain double-click may be refused the first time. The fix is in First run on a Mac.

Where do my configs and results go?

They stay on the device. The full list of what the app connects to is in this section.

How do I know the file I downloaded is untouched?

Each release has SHA256SUMS-… files next to the downloads. Hash your file and compare it with that file's line. On Windows:

certutil -hashfile IRNetFree-Plus-Setup-x.y.z.exe SHA256

On macOS and Linux: shasum -a 256 <file> or sha256sum <file>
